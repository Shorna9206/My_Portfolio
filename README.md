# Rokeya Shorna — Premium Portfolio 

A responsive, animation-first professional portfolio built from Rokeya Shorna's supplied CV materials.

## Included
- React + Vite
- Framer Motion page transitions
- GSAP + ScrollTrigger reveal animations that play/reverse as sections enter/leave the viewport
- Lenis smooth scrolling
- Three.js interactive 3D visual
- Compact professional portrait card using the supplied CV portrait
- Responsive mobile navigation and layouts
- Dark / light theme
- Magnetic/hover-style CTA buttons and interactive project cards
- Projects, project details, experience, education, research/publications, awards, workshops, leadership, references, hobbies and resume pages
- Print-friendly resume page
- Contact form endpoint support through `VITE_CONTACT_ENDPOINT`
- Reduced-motion accessibility behavior
- Vercel-ready Vite configuration

## Run
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Optional contact endpoint
Copy `.env.example` to `.env` and set:
```env
VITE_CONTACT_ENDPOINT=your_endpoint_here
```

Without an endpoint the contact form stays in demo mode and provides a direct email fallback.
